# AI Market Signals Analyzer

Render deployment:
- Build Command: npm install
- Start Command: npm start
- Root Directory: empty
- Runtime: Node

Features:
- Forex, commodities, indices, crypto and stocks
- Candlestick chart
- RSI, EMA 9/21/50, MACD, ATR
- Support/resistance
- BUY / SELL / WAIT technical signal
- Confidence score
- WebSocket live refresh architecture

Important:
This uses public market data and technical calculations. It is not an exact Quotex/OTC feed and signals are not guaranteed predictions.
